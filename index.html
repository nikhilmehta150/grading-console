Marks file format guidance

The Excel file should contain exactly three columns: BITS ID, Course, and Total Marks.

Total Marks should be whole numbers from 0 to 100. Fractional values are rounded to the nearest integer.

Students to be awarded an NC grade should not be included in the file.
